# Releases

| File | Type | Use |
|---|---|---|
| `GMUniversalGrid_1.0.4.0_managed.zip` | Managed | Production / test environments (recommended) |
| `GMUniversalGrid_1.0.4.0_unmanaged.zip` | Unmanaged | Development environments |

`https://github.com/gmanunta81/GM-Universal-Grid-Control/releases`
